Shown when a request succeeded but returned nothing. `title` is the headline,
`description` an optional supporting line.

```jsx
<EmptyState
  title="Nenhum requisito cadastrado."
  description="Crie o primeiro requisito para começar a rastrear."
/>
```

Write the description as the next action the user can take, not as an apology.
